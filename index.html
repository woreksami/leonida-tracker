        07 · Method

        How the estimates work

        First boot

        Leonida's developers expect booting to take 1 to 3 days after a retail exe reaches them. The tracker starts from that window and stretches or shrinks it by how fast work is landing: pull requests merged in the last 24 hours against the 24 hours before, capped at ±25% so one big merge round can't swing it. When the boot task (RT-5) is claimed the phase changes to "Recompiling"; when its pull request merges, to "Booted".

        Graphics layer

        Items on the graphics board not yet merged, divided by graphics pull requests merged per hour over the last two days. The range uses the last 24 hours as the second speed.

        Ladder

        Groundwork is the share of rows in Leonida's README status table marked done (✅ = 1, ⚠️ or ? = ½). Higher rungs light up only on the project's own signals: the README's boot row, or the boot task merging. Playable has no date: nobody can know until the game boots.

        LeonidaTracker

        Data: the public Leonida repository, read straight from your browser. Estimates are projections, not promises. Source: woreksami/leonida-tracker.

        Fan-made and unofficial. Not affiliated with Rockstar Games, Take-Two Interactive or Microsoft. Leonida ships no game files: players supply their own legally owned copy. The exe noted above is a tester's private copy and is never shared.

        The "here now" count uses two free public MQTT servers (broker.emqx.io and test.mosquitto.org): your browser sends them only a random id and a timestamp. Anyone can connect to them, so treat the number as approximate.
